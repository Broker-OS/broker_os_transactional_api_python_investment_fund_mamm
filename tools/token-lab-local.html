sin conectar

Todo contra tu cadena local. Sin MetaMask, sin faucet, sin límites.

Desplegar el token

Crea una moneda nueva en la cadena. Normalmente no hace falta usar esta pestaña: ya hay un token desplegado y configurado en el .env de cada lado.

Solo la necesitás si reiniciaste tu ganache local —ahí la cadena se borra y hay que crear todo de nuevo— o si querés una moneda distinta.

Esa cuenta recibe el 1.000.000 inicial y queda como dueña, así que es la única que después puede emitir más. Con dejar la (0) alcanza.

Si desplegás uno nuevo, el anterior deja de servir: hay que copiar la dirección nueva a EVM_USDC_CONTRACT en el .env y reiniciar la API.

Enviar tokens

Cada envío genera un hash: ese es el comprobante que le presentás a la API para que lo verifique.

Cuentas de la cadena

Las 10 cuentas de prueba que trae la cadena, con lo que tiene cada una. La marcada como receptora es la que hace de caja: ahí llegan los pagos que después verifica la API.

Las dos columnas no son lo mismo.
USDC es el dinero: cada unidad representa un dólar, y es lo que se transfiere y se cobra.
Saldo para comisiones es el combustible: cada operación en la cadena cuesta una comisión mínima que se paga con esto. No es plata que cobres.
